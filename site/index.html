Comment ça marche

Pas de site à garder ouvert dans un coin, pas de copier-coller depuis un navigateur. Tout se passe dans VS Code, sur tes propres projets.

  1. Ouvre un dossier vide

    Ce sera ton workspace, celui de tes projets Rust. Clique sur l'icône Learn Rust dans la barre d'activité.

  2. Lis la leçon

    Elle s'ouvre à gauche, ton code à droite. Une leçon se lit en un quart d'heure, avec des questions pour vérifier que c'est clair.

  3. Code dans ton terminal

    Tu crées tes projets avec cargo new. Les étapes se cochent toutes seules quand l'extension voit le fichier, le build ou le test.

  4. Clique sur Vérifier

    Ça lance cargo test. Les erreurs du compilateur s'affichent dans ton code, grâce à rust-analyzer.

Ce que tu y trouves

Le Rust Book, en français

Le parcours suit les chapitres du livre officiel, dans le style de sa traduction française. Chaque leçon se suffit à elle-même : pas besoin de lire le livre à côté.

Des leçons interactives

Des blocs « À toi » au fil du texte, des questions qui révèlent leur réponse une par une, et le code de départ prêt à copier sous chaque étape.

Depuis TypeScript

Des encarts « Côté TypeScript » à déplier font le pont avec ce que tu écris déjà. Ils restent fermés si tu n'en as pas besoin.

Le compilateur comme prof

Avant de coller un exercice qui ne compile pas, tu prédis l'erreur. Puis tu lis le vrai message, là où il apparaît : dans ton éditeur.

Ta progression chez toi

Elle est enregistrée dans .learn-rust/progress.json, dans ton workspace. Rouvre-le, et tout se remet en place là où tu t'étais arrêté.

Avec ton IA, si tu veux

L'extension n'embarque pas d'IA. Garde celle que tu as déjà, Claude Code, Copilot ou Cursor, et demande-lui des indices plutôt que du code.

Commencer

1. Installe Rust

Il te faut cargo et rustc, que rustup installe en une commande. rust-analyzer arrive tout seul avec l'extension.

$ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

2. Installe l'extension

Depuis le Marketplace, ou en ligne de commande. Ouvre ensuite un dossier vide et clique sur l'icône Learn Rust.

$ code --install-extension velstudio.learn-rust
