Quelques principes

Tu écris, il questionne

Le tuteur ne donne jamais la solution. Il t'aide à trouver avec des questions, puis des indices en trois paliers si tu bloques.

Le cours d'abord

Chaque exercice part d'une section du Rust Book, version Brown, avec ses quiz. Puis tu pratiques sur un petit crate.

Depuis TypeScript

Chaque notion arrive avec son équivalent TS et ce qui change vraiment. Tu pars de ce que tu sais déjà.

À ton rythme

Des séances de trente minutes. Te tromper fait partie du jeu : le compilateur explique, et le tuteur se souvient de ce qu'il faut revoir.

Deux façons de commencer

Suivre la formation

Clone le repo, lance Claude Code et tape /next. Il te faut rustup, Claude Code, Node 22 et jq.

$ git clone https://github.com/matschik/learn-rust-for-web-devs.git
$ cd learn-rust-for-web-devs && claude
> /next
Lire la première fiche

En faire ta version

Forke le repo et présente-toi dans un CLAUDE.local.md : prénom, stack, préférences. Tu viens de Python ou de Go ? Réécris la section « L'apprenant » de CLAUDE.md et le tuteur fait le pont avec ton langage.

Tout est versionné : le contrat du tuteur dans CLAUDE.md, les commandes dans .claude/commands, les exercices dans modules.
