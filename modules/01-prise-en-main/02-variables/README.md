# 02 - Variables · pratique

Coche les étapes au fil de l'eau dans le dashboard. Le tuteur s'en sert aussi pour savoir où tu en es.

## Étapes

### Cours

- [ ] Lis la leçon jusqu'au bout.
- [ ] Réponds de tête aux questions de « Teste-toi », puis vérifie tes réponses.

### Pratique

- [ ] Ouvre `src/lib.rs`. Cet exercice ne compile pas, c'est voulu.
- [ ] Prédis l'erreur que le compilateur va donner, et sur quelle ligne.
- [ ] Lance `cargo test -p m01_e02_variables` et lis l'erreur en entier, code compris (par exemple E0384).
- [ ] Corrige `count_done` en changeant le moins de choses possible.
- [ ] Corrige `trimmed_title_len` de la même façon. Ne touche pas aux tests.
- [ ] Relance les tests jusqu'à ce qu'ils passent tous.
- [ ] Lance `/review` dans Claude Code et explique ton code en deux phrases.
