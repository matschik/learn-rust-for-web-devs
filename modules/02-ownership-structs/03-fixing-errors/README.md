# 03 - Corriger les erreurs d'ownership · pratique

Relis la fiche de cours (`COURS.md`) si besoin, puis lance-toi.

## À faire

Ne compile pas. Lance `cargo test -p m02_e03_fixing_errors` et prends les erreurs **une par une**.

Pour chacune, avant de corriger :

1. Dis quelle permission (R, W ou O) manque, sur quel chemin, et à quelle ligne elle a été perdue.
2. Dis ce qu'aurait fait JS à la place, et pourquoi Rust refuse.

Aucun `.clone()` autorisé dans cet exercice.
